# Imagens

Recursos locais, usados para identificar os jogos no catálogo e no instalador.
As ilustrações pertencem aos respectivos titulares; não são arte original
nem uma declaração de afiliação com os jogos.

| Arquivo em `drawable-nodpi` | Origem |
| --- | --- |
| `fate_cafe_logo.webp` | Logo já presente neste repositório |
| `fgo_key_art.webp` | `fate-cafe-react/src/assets/optimized/home/area-servos.webp`, ilustração de Fate/Grand Order (TYPE-MOON / FGO PROJECT) |
| `blue_archive_key_art.jpg` | Cápsula promocional da página oficial de Blue Archive no Steam, NEXON Games / NEXON Korea |

Blue Archive: [página do jogo](https://store.steampowered.com/app/3557620/),
[imagem de origem](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/3557620/556b95073d10aea23fd1ae38eebd9e8a06647f4f/capsule_616x353.jpg).

Nenhuma fonte externa é baixada. A interface usa as famílias serifada e
sem serifa do Android, mantendo acessibilidade, acentuação e funcionamento offline.
