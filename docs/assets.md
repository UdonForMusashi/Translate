# Imagens

Recursos locais, usados para identificar os jogos no catálogo e no instalador.
As ilustrações pertencem aos respectivos titulares; não são arte original
nem uma declaração de afiliação com os jogos.

| Arquivo em `drawable-nodpi` | Origem |
| --- | --- |
| `fate_cafe_logo.webp` | Logo já presente neste repositório |
| `fgo_key_art.webp` | `fate-cafe-react/src/assets/optimized/home/area-servos.webp`, ilustração de Fate/Grand Order (TYPE-MOON / FGO PROJECT) |
| `blue_archive_key_art.jpg` | Arona, Key Visual 1 de Blue Archive The Animation, disponível na Blue Archive Wiki (NEXON Games / Yostar) |

Arona: [página da imagem na wiki](https://bluearchive.wiki/wiki/File:Blue_Archive_the_Animation_Key_Visual_1.jpg),
[original de 2480 × 3164](https://static.wikitide.net/bluearchivewiki/9/97/Blue_Archive_the_Animation_Key_Visual_1.jpg).
O recurso local usa a versão de 800 px publicada pela wiki, suficiente para a área
exibida no app. O catálogo centraliza a composição vertical; o banner de acesso
mantém o rosto da Arona no enquadramento. A imagem original não foi retocada.

Nenhuma fonte externa é baixada. A interface usa as famílias serifada e
sem serifa do Android, mantendo acessibilidade, acentuação e funcionamento offline.
